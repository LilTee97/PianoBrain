# Chat mẫu với Mr Hai

Chạy bằng `npm run chat`. Sinh lại bằng `npx tsx src/mrhai/chatDemo.ts`.

```text
Em: vòng C Am F G trên tone C xếp bậc sao

Thầy: C=I, Am=vi, F=IV, G=V (tông C)
```

```text
Em: thầy dạy A7b9 trước F trên 1645 chưa?

Thầy: "thầy dạy A7b9 trước F trên 1645 chưa?": CHƯA CÓ.
  Cặp hợp âm em hỏi sai chức năng nên thầy không dựng. Muốn chèn át 7b9 thì đích phải là hợp âm thứ, ví dụ E7b9 về Am.
  [kiểm kê] CHƯA CÓ — thầy 0, draft 0, seed 0
```

```text
Em: câu lót vòng 1 6 4 5 giọng C

Thầy:   · [của thầy] Kỹ thuật tạo câu lót/câu dẫn trên tiến trình C -> C/E -> F: Giữ hình tiết tấu (motif) nố  (tap-01-bai-07-lesson-id-00003)
  · [của thầy] Dùng nốt bậc 9 để chạy câu dán/câu lót (fill-in) khi chuyển hợp âm: Tay trái giữ 1-5 hoặ  (tap-02-bai-08-tap-02-bai-08-011)
```

```text
Em: chạy ngón trên C Am F G

Thầy:   [suy từ nguyên lý] C → Am, hạ cánh C5:
  C4 - D4 - E4 - G4 - E4 - G4 - A4 - B4 - C5
  ngón 1-2-3-5-1-2-3-4-5, tay trái C2 - G2 - C3
```
